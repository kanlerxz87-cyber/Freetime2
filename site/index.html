How the free-time model works

  • Specific published event times are treated as on-air from kickoff/first pitch through the estimated event duration.
  • Unreleased or unsourced game schedules are not invented as individual rows. Calendar uses broad season-window blocks, marked ESTIMATED.
  • For game-day free time by hour, only time-known entered events are given approximate end times using researched duration assumptions. Dates with incomplete schedules are not labeled verified free.
  • All displayed schedule rows include source links; source type and confidence are visible.
