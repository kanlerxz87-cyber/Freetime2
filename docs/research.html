Verification method

  1. Each schedule row was read from the official team, league or network page for the game and matched to a source link.
  2. Times were read as published, converted to Pacific by subtracting 3 hours from ET (all dates are in Pacific Standard Time), and checked against a second official source where one exists. Conflicts are flagged, not resolved.
  3. MLB games were read from the MLB Stats API live in the browser, not copied by hand. Each MLB row links to its game feed.
  4. Where a value could not be confirmed from an official source, the cell is left blank or labelled UNVERIFIED. Nothing was inferred.
  5. Reference sites in the brief: RADIOSF and VacationSchedule did not load; ScheduleFreeTime was not fetched. None of their content was used.
