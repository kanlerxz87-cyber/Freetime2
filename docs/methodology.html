Methodology & Day Planner

How free time is calculated

  1. Mark season blocks busy (MLB Spring Training→World Series; NFL preseason→Super Bowl; NCAAF regular season→CFP title).
  2. For specific verified game dates, add game blocks: start time + average duration.
  3. Free = minutes outside all blocks (PT). For vacation purposes, any date inside a season block = NOT free, even if hourly gaps exist.
