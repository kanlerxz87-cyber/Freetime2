METHODOLOGY · MODEL CARD

How we decide a day is “free.”

Short version: a day is busy if anything in scope is on the air. Free time on game days is whatever’s left. Every number is labeled verified or estimated; the estimator is deterministic (seeded) so results reproduce run-to-run.

2 · Busy / free definitions

STRICT

Count any row from in-scope streams (MLB all clubs incl. ST/postseason; all NFL incl. preseason/SB/Pro Bowl; Stanford/Cal NCAAF incl. bowls/CCG placeholders). A TBD/untimed row makes the day busy without allocating hours.

PRACTICAL

Count only priority=high rows: Giants/A’s MLB fixtures, 49ers NFL fixtures, Stanford/Cal NCAAF, Westwood One national NFL. Reflects what a Bay Area AM/FM listener can actually avoid missing.

OUT OF SCOPE

Other NCAAF (informational rows listed but never block), NBA/NHL/MLS/NWSL (Warriors/Sharks etc.), golf, soccer, tennis, betting shows, replays. They consume dial time but aren’t vacation blockers in this model.

3 · Daily interval math

  1. Collect every in-scope row for the date; drop out-of-scope/informational rows.
  2. Timed rows → interval [start, start + minutes] (PT). Untimed rows → count flag only.
  3. Merge overlapping intervals (games can’t un-overlap). Sum merged minutes → busy.
  4. free = 1440 − busy. Free intervals are the complement; they render on the Scoreboard timeline.
  5. Day is FREE iff busy == 0 and untimed rows == 0.
  6. Windows = runs of ≥3 free days (we report ≥5, ≥7, ≥14 too).

DST: PT dates are calendar dates in America/Los_Angeles; a game at 10:00 PT is one PT calendar day regardless of UTC offset (PDT/PST handled by the date key, not by timestamp arithmetic).

5 · Known failure modes

  • Reconstructed fixtures can put two games on one club the same day — generator enforces ≤15 games/day total and team-day uniqueness, but opponent realism (division rotations, international placeholders) is not guaranteed.
  • Row-level verification is impossible here; the site never claims “confirmed” for a generated row.
  • Multi-day window math uses day granularity — a 4-day window split by a single arbitrary TBD game would read as two separate windows if both ≥3 days.
  • Travel/jetlag (Melbourne 2026 opener = 8:35 PM PT) is irrelevant to radio blocking but matters if you attend in person.
  • OT/extra innings not modeled; they always extend, never shorten, a block.
