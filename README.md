# Free Time Vacation

A static GitHub Pages planning dashboard for Bay Area sports and vacation timing. Open `index.html` locally or serve the repository root. Navigation uses hash routes so it works under a GitHub Pages project path without a build step.

**Important:** the included event list is a small manually sourced sample, not complete coverage. No date or interval can be certified free. Radio carriage and reception need per-game confirmation. See the Flagged for Review page for outstanding work and assumptions. The UI uses Pacific local time including daylight saving, not fixed PST year-round.

Data was checked against the linked official sources on 2026-11-25. The sample is static and does not automatically update. Start times and dates can change. MLB durations use a historical 158-minute nine-inning average; 180 minutes for NFL is an explicitly unverified planning assumption, not a measured average. Neither includes pregame or postgame radio coverage.
