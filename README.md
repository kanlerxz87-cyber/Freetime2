# Free Time Vacation

Static GitHub Pages research prototype for Bay Area radio sports vacation planning. Open `index.html` or serve the repository with `python3 -m http.server`. No build or dependencies required.

**Coverage is incomplete.** Missing listings are not free days; the planner does not verify any vacation window. See [Flagged for Review](flagged.html) for specific omissions, and [Method](methodology.html) for time zone and estimates. Data snapshot: 2026-11-25. `assets/data.js` is a manually transcribed subset, not a live feed.
